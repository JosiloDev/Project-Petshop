# Pet Shop
 
Desktop Java (Swing) system for managing pets at a pet shop.
 
## Features
- Register a pet (name, age, breed, owner name and phone)
- Search for a pet by name
- Update a pet's data
- Remove a pet
Shortcuts: `Enter` to register, `F2` to search, `F3` to update, `F4` to remove.
 
## How to run
javac *.java
java ClinicaVeterinaria
 
## Tech stack
- Java
- Swing (GUI)
